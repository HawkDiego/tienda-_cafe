# CafeGuito

Landing de tienda de café de origen colombiano. Textos de UI, commits y comentarios en español.

- Metodología: OpenSpec (`openspec/`, comandos `/opsx:*`). Contexto y reglas del proyecto en `openspec/config.yaml`.
- Comandos: `npm run dev`, `npm run build`, `npm run lint`. No hay suite de pruebas.
- Despliegue: Vercel Hobby (gratis) vía MCP de Vercel, dominio `*.vercel.app`.
